# Liste de tâches

Petite application web pour gérer ses tâches, réalisée en HTML, CSS et JavaScript (sans framework).

## Fonctionnalités
- Ajouter une tâche
- Marquer une tâche comme faite (clic sur le texte)
- Supprimer une tâche
- Compteur de tâches restantes
- Sauvegarde automatique dans le navigateur (localStorage)

## Technologies
- HTML5 : structure
- CSS3 : mise en forme
- JavaScript : logique et interactions

## Lancer le projet
Ouvrir le fichier `index.html` dans un navigateur.
